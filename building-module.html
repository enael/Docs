Classe BuildingModule

Composant autonome de sous-système pour bâtiment (Stockage, Atelier, UI, etc.).

Description Générale

BuildingModule sert de classe de base pour tous les sous-composants pouvant être attachés à un Building. Elle fournit les fonctions nécessaires pour réserver/libérer des emplacements de stockage, exécuter une tâche (Work), et générer dynamiquement l'interface utilisateur associée (bandeau court ou fenêtres d'information détaillées).
