Page 2 : Classe Building & Inventaires

Spécification des éléments centraux du composant principal Building.

1. Attributs Clés du Building

Variable Type Description
UI UIBuilding Interface graphique du bâtiment hébergeant les UIs des modules.
Storages List<Storage> Réserves permanentes gérées par le bâtiment.
Slots List<BuildingSlot> Emplacements disponibles pour équiper des modules.

2. Méthodes Appelées par les Modules

  • Storage GetStorage(RESOURCE resource) : Recherche et réserve un stockage libre adapté à la ressource.
  • void UnreserveStorage(Storage storage) : Libère l'accès à un stockage précédemment réservé par un module.
  • void DestroyAllStorages(List<Storage> storages) : Supprime définitivement la liste de stockages spécifiée.

Page 3 : Classe BuildingModule & Interface UI

Gestion des comportements, des ressources et des fenêtres dynamiques.

1. Variables de BuildingModule

Variable Type Description
UIUIBuildingModulePréfab UI pour la vue raccourcie/liste du bâtiment.
UIWindowGameObjectPréfab de la fenêtre détaillée (instancié dynamiquement).
BuildingBuildingRéférence vers le bâtiment maître.
StoragesList<Storage>Liste des stockages actuellement gérés par ce module.

2. Méthodes du Cycle de Vie du Module

  • virtual void Install(Building building) : Initialise le module, duplique son UI et l'associe au bâtiment.
  • virtual void Uninstall() : Déconnecte l'UI et libère tous les stockages réservés.
  • virtual void Work() : Point d'entrée virtuel exécuté à chaque cycle de travail du module.

3. Gestion de l'UI Détaillée (CreateDetailedUI)

La méthode CreateDetailedUI est responsable du réparentage dynamique d'une fenêtre dans le conteneur UI :

public void CreateDetailedUI(UIWindowBuildingModulesContainer container) { if (UIWindow == null) return; // 1. Instanciation du préfab UI GameObject tempRoot = Instantiate(UIWindow); Transform realPanel = tempRoot.transform; // 2. Configuration du RectTransform pour le Layout RectTransform rect = realPanel.GetComponent<RectTransform>(); rect.anchorMin = new Vector2(0, 1); rect.anchorMax = new Vector2(0, 1); rect.pivot = new Vector2(0.5f, 1f); rect.anchoredPosition = Vector2.zero; // 3. Attachement au conteneur cible realPanel.SetParent(container.ContainerModules.transform, false); // 4. Enregistrement auprès du script UI parent UIWindowBuildingModule uiwindow = realPanel.GetComponent<UIWindowBuildingModule>(); if (uiwindow != null) { uiwindow.Initialize(this); container.AddModule(uiwindow); } }
