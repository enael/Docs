Vue d'Ensemble du Système de Bâtiments

Documentation technique de l'architecture logicielle pour les structures et leurs modules.

1. Description Générale

Le système repose sur une architecture modulaire composée de trois piliers principaux :

  • Building : L'entité centrale gérant le statut général, les inventaires permanents et temporaires, le visuel et les accès des unités.
  • BuildingModule : Composant dérivable attaché à un bâtiment pour lui fournir des comportements spécifiques (stockage, production, défense, etc.).
  • BuildingSlot : Point d'ancrage liant un BuildingModule à son hôte Building.

2. Enumérations de Base

MODULE_TYPE : Définit la catégorie fonctionnelle d'un module.

  • OCCUPANCY : Gestion des habitants et travailleurs.
  • STORAGE : Extension des capacités de stock.
  • WORKSHOP : Production et artisanat.
  • DEFENSE : Tourelles et structures de garde.
  • EXTENSION : Agragations diverses.
