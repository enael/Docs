1. Building : MonoBehaviour Gère l'état, la construction, les unités, les stockages et l'UI d'un bâtiment. 🛠️ Variables Name (string) : Nom du bâtiment. Type (BUILDING) : Type du bâtiment (Enum). Status (BUILDING_STATUS) : État (PLACEMENT, CONSTRUCTION, COMPLETE). Enable (bool) : État d'activité du bâtiment. UI (BuildingUI) : UI monde attachée. InfoWindow (InfoWindowBuilding) : Ancienne fenêtre d'info. Slots (List) : Slots de modules disponibles. Storages / ConstructionStorages (List) : Stockages permanents / de chantier. InUnits / ExitingUnits (List) : Unités à l'intérieur / en cours de sortie. PersistentCircle (bool) : Affiche la zone d'effet au sol. ⚙️ Fonctions InitializePlacement() / InitializeContruction() / ConstructionDone() → void : Cycle de vie du bâtiment. Work() → void : Boucle principale (gère la construction ou les modules + sorties d'unités). InitializeModules() / InstallModule(slot, prefab) → void : Installe les modules dans les slots. GetStorage(resource) / GetConstructionStorage() → Storage : Réserve un emplacement de stockage. UnreserveAllStorages(list) / DestroyAllStorages(list) → void : Nettoyage des stockages. UnitEnter(unit) / UnitExit() / UnitDie(unit) → void : Gestion des unités entrantes/sortantes. ShowTerrainCircle() / SetPersistentCircle(state) → void : Gestion des cercles de zone. 2. BuildingSlot & BuildingModule : MonoBehaviour BuildingSlot définit un emplacement. BuildingModule est la classe de base des composants installables. 🛠️ Variables (BuildingModule) UI (UIBuildingModule) : Prefab UI compacte (monde). UIWindow (GameObject) : Prefab UI détaillée (fenêtre). Building (Building) : Bâtiment parent. Storages (List) : Stockages réservés par ce module. ⚙️ Fonctions (BuildingModule) Install(building) → void : Attache le module au bâtiment et instancie l'UI compacte. Uninstall() → void : Libère les stockages et supprime l'UI. Work() → void : Logique interne exécutée par Building.Work(). GetStorage(resource, type, priority, ...) → Storage : Réserve un stockage sur le bâtiment. CreateDetailedUI(container) → void : Instancie l'UIWindow et l'ajoute au conteneur UI. 3. BuildingUI : GameObjectUI, UILanguage Suivi UI 3D -> ScreenSpace positionné au-dessus du bâtiment. 🛠️ Variables UIPivotPoint (GameObject) : Point d'ancrage 3D. ModulesContainer (GameObject) : Parent des icônes UI compactes. moduleUIs (List) : Liste des UI compactes actives. ⚙️ Fonctions Update() → void : Exécute UpdateUIPosition() à chaque frame. AddModule(module) / RemoveModule(module) → void : Ajoute/retire un module UI et réordonne. UpdateUIPosition() → void : Convertit la position 3D de UIPivotPoint en coordonnées écran/UI. 4. UIWindowBuildingModulesContainer : UIWindowStack Fenêtre principale listant les UI détaillées des modules (UIWindowBuildingModule). 🛠️ Variables Building (Building) : Bâtiment lié. ContainerModules (GameObject) : Parent UI recevant les fenêtres de modules. modules (List) : Modules UI actifs dans la fenêtre. ⚙️ Fonctions InitializeContainer(building) → void : Lie le bâtiment et active OK/Cancel si nécessaire. Open(params) → int : Force le recalcul de taille (LayoutRebuilder) des enfants, du conteneur et du panel avant ouverture. CloseWindow(event) → void : Exécute Apply() (si YES) ou Cancel() (si NO) sur tous les modules UI. AddModule(module) / ClearModules() → void : Gestion de la liste des modules UI. 5. InfoWindowBuilding : UIWindowStack, UILanguage Panneau d'information basique (activation du bâtiment et zone persistance). 🛠️ Variables Title (TextMeshProUGUI) : Titre traduit. Building (Building) : Bâtiment lié. Enable / Disable (GameObject) : Boutons d'état ON/OFF. TogglePersistentCircle (Toggle) : Case à cocher pour le cercle au sol. ⚙️ Fonctions Initialize(building) → void : Lie le bâtiment et configure les événements UI. EnableBulding() / DisableBulding() → void : Alterne l'état actif/inactif. PersistentCircleToggleChange() → void : Active/désactive le cercle de zone du bâtiment. 6. UIBuildingModule : MonoBehaviour Composant UI compact rattaché au BuildingUI. 🛠️ Variables & Fonctions Module (BuildingModule) : Référence du module logique. Initialize(module) → void : Assigne le module. 7. UIWindowBuildingModule : MonoBehaviour, UILanguage Base des panneaux UI modulaires insérés dans UIWindowBuildingModulesContainer. 🛠️ Variables Title (string) : Clé de traduction. TitleField (TextMeshProUGUI) : Affichage du titre. ⚙️ Fonctions Initialize(module) → void : Enregistre le handler de traduction. NeedValidation() → bool : Retourne true si le module nécessite les boutons Valider/Annuler (défaut : false). Apply() / Cancel() → void : Exécutés à la fermeture de la fenêtre selon le choix du joueur.
